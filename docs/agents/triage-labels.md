# Triage Labels

| Canonical role | GitHub label | 意義 |
|---|---|---|
| needs-triage | needs-triage | 等待評估 |
| needs-info | needs-info | 等待補充資訊 |
| ready-for-agent | ready-for-agent | 可交由 agent 處理 |
| ready-for-human | ready-for-human | 需要人工實作 |
| wontfix | wontfix | 不處理 |

工程 skills 提及 triage role 時，使用對應的 GitHub label。
標籤不取代使用者明確要求的實作前確認。
