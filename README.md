# 本地英文句型練習

在這個 Codex 專案說「開始句型練習」，用 Codex 聽寫回答英文；也可以打字。每天不需要另外載入指揮文件。

| 說法 | 結果 |
|---|---|
| 開始／繼續句型練習 | 有未完成回合就接續，否則選到期複習或新教材 |
| 暫停 | 保存目前階段，換聊天後可繼續 |
| 結束／同步／幫我保存 | 結算成果與下次複習；提前結束不補題 |
| 保存了嗎／查看進度 | 只讀查詢 |
| 換新回合 | 先成功結算目前回合 |
| 聽寫錯了，應該是… | 保留原文及更正；結算後先提出修復影響供確認 |
| 匯入這份教材 | AI 轉換、保存來源、預覽差異，接受後才生效 |

每回合預設4–6個中文情境，一個主句型，最多穿插一個舊句型。新教材先短介紹介句，複習先提取。回饋先看句型／意思，再處理一個有價值的問題；收尾包含一個無提示新情境。聽寫僅提供文字證據，不評分發音或速度。

教材一份來源一個 JSON，每筆只必填 `pattern`、`purpose`、`examples`。不用手填 ID、版本或進度；AI 可將文章、表格、筆記轉換成相同格式。[教材格式](docs/material-source-format.md) 有完整例子。草稿修改不立即影響練習，接受修訂後才供新回合使用。

`materials/` 是可維護教材，`data/practice.sqlite3` 保存已接受版本、證據及進度，`data/imports/` 留原始來源與核對報告，`data/backups/` 留完整校驗備份。這些個人檔案不進 Git，plugin 更新也不會替換它們。舊 Notion 已唯讀遷移，日常不再連線 Notion；缺少的歷史時間或逐字稿不補造。

重裝、還原與工程驗證見 [維護說明](docs/maintenance.md)。實作／驗收狀態見 [實作紀錄](docs/implementation-notes.md)。
